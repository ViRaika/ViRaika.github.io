## Running Locally

Clone the repo:

git clone https://github.com/viraika/viraika.github.io.git
cd viraika.github.io

Install dependencies and run:

bundle install
bundle exec jekyll serve

Open:

http://localhost:4000

## Blog Philosophy

If a concept can survive:
1. confusion,
2. rewriting,
3. explaining it to yourself,
4. and debugging at 2 AM,

then maybe you actually learned it.

This site is basically that process in public.
